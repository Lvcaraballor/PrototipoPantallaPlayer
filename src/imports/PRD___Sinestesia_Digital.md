# PRD — Sinestesia Digital

**Product Requirements Document**  
**Versión:** 0.1 — Primer prototipo funcional  
**Tipo de producto:** Experiencia web hipermedia interactiva  
**Modalidad:** Proyecto individual  
**Asignatura:** Ingeniería de Prompt

# 1. Información general

## 1.1. Nombre del producto

**Sinestesia Digital**

### Subtítulo

**Prototipo de una experiencia hipermedia interactiva entre música y lenguaje visual.**

---

# 2. Resumen del producto

**Sinestesia Digital** es una experiencia web hipermedia que explora cómo las características de diferentes géneros musicales pueden ser interpretadas y traducidas mediante recursos visuales e interactivos.

El proyecto parte de la relación entre **sonido, percepción, imagen e interacción**, utilizando elementos como ritmo, energía, tempo, intensidad y frecuencia para generar diferentes respuestas visuales.

El primer prototipo estará compuesto por tres categorías musicales:

- Música urbana: reguetón y trap.
- Afrobeats.
- Tecno.

Para esta primera versión se desarrollarán **6 experiencias visuales**, correspondientes a dos canciones predeterminadas por cada género.

La visualización reaccionará automáticamente al audio, mientras que el usuario podrá intervenir en diferentes aspectos de la experiencia mediante controles e interacciones.

---

# 3. Problema

La música suele experimentarse principalmente mediante el sentido auditivo. Aunque existen visualizadores musicales, muchas experiencias digitales utilizan representaciones genéricas que no necesariamente exploran las características particulares de cada género.

Cada género musical posee elementos distintivos relacionados con:

- Ritmo.
- Tempo.
- Intensidad.
- Frecuencia.
- Repetición.
- Estructura.
- Energía.

Estos elementos pueden convertirse en recursos de diseño visual.

El problema que aborda **Sinestesia Digital** es:

> **¿Cómo pueden traducirse visualmente las características de diferentes géneros musicales mediante una experiencia web interactiva?**

El proyecto no busca establecer una representación visual definitiva para cada género, sino **explorar diferentes interpretaciones visuales mediante el Diseño Hipermedia y la Ingeniería de Prompt**.

---

# 4. Oportunidad

Existe una oportunidad para desarrollar experiencias digitales en las que el usuario no solamente escuche música, sino que pueda **ver, manipular y experimentar visualmente sus características**.

La combinación de:

- Música.
- Diseño visual.
- Animación.
- Interactividad.
- Programación web.
- Inteligencia artificial.
- Ingeniería de Prompt.

permite crear una experiencia más inmersiva y participativa.

---

# 5. Propósito del producto

Crear un espacio digital donde el usuario pueda experimentar una conexión entre **música, imagen, interacción y percepción**, explorando diferentes maneras de representar visualmente los géneros musicales contemporáneos.

La experiencia busca generar una sensación de:

- Conexión con la música.
- Conexión con los elementos visuales.
- Conexión mediante la interacción.
- Conexión emocional con la experiencia.
- Integración entre sonido y espacio digital.

---

# 6. Objetivo general

**Diseñar y desarrollar un prototipo web hipermedia funcional que explore la traducción de características musicales en representaciones visuales mediante animación, interacción y recursos gráficos.**

---

# 7. Objetivos específicos

1. Explorar cómo características musicales como ritmo, tempo, intensidad y frecuencia pueden representarse mediante elementos visuales.

2. Desarrollar diferentes identidades visuales asociadas a música urbana, afrobeats y tecno.

3. Diseñar una interfaz que permita al usuario seleccionar y experimentar diferentes propuestas musicales y visuales.

4. Implementar visualizaciones que reaccionen automáticamente a las características del audio.

5. Incorporar interacciones que permitan al usuario modificar diferentes aspectos de la experiencia visual.

6. Utilizar herramientas de Ingeniería de Prompt e inteligencia artificial para explorar y desarrollar propuestas visuales.

7. Construir un prototipo funcional utilizando Figma y tecnologías web como HTML, CSS y JavaScript.

8. Establecer una estructura flexible que permita incorporar nuevas experiencias, géneros y funcionalidades en futuras versiones.

# 9. Propuesta de valor

**Sinestesia Digital** permite experimentar la música desde una perspectiva visual e interactiva.

A diferencia de un reproductor musical tradicional, el producto busca que:

> **La música no solamente se escuche, sino que también pueda observarse, explorarse y modificarse.**

La propuesta combina:

**Música + Visualización + Interacción + Diseño Hipermedia + IA**

# 18. Relación audio → visual

El prototipo utilizará las siguientes relaciones:

| Característica del audio | Respuesta visual |
|---|---|
| Ritmo | Movimiento |
| Bajos | Tamaño de formas |
| Frecuencias altas | Partículas |
| Intensidad | Brillo y escala |
| Silencios | Disminución del movimiento |
| Cambios musicales | Transformaciones visuales |

Estas relaciones serán una **interpretación de diseño**, no una traducción científica o universal de la música.

> Como usuario, quiero seleccionar un género musical para experimentar una visualización relacionada con sus características.

### Reproducción

> Como usuario, quiero reproducir y pausar la música para controlar mi experiencia.

> Como usuario, quiero cambiar de canción para comparar diferentes experiencias visuales dentro de un mismo género.

### Interacción

> Como usuario, quiero interactuar con los elementos visuales para sentir que participo en la experiencia.

### Personalización

> Como usuario, quiero modificar características de la visualización para crear una experiencia que se adapte a mis preferencias.

### Exploración visual

> Como usuario, quiero cambiar entre diferentes visualizaciones para observar distintas interpretaciones de la música.

# 22. Requisitos funcionales

## RF-01 — Inicio

El sistema deberá mostrar una pantalla inicial con acceso a la experiencia.

## RF-02 — Selección de género

El sistema deberá permitir seleccionar entre:

- Urbano.
- Afrobeats.
- Tecno.

## RF-03 — Selección de canción

El sistema deberá permitir seleccionar dos canciones predeterminadas por género.

## RF-04 — Reproducción

El sistema deberá reproducir el audio seleccionado.

## RF-05 — Visualización reactiva

El sistema deberá generar cambios visuales relacionados con el comportamiento del audio.

## RF-06 — Control de reproducción

El usuario deberá poder reproducir, pausar y reiniciar la canción.

## RF-07 — Control de volumen

El usuario deberá poder modificar el volumen.

## RF-08 — Cambio de experiencia

El usuario deberá poder cambiar de canción o género.

## RF-09 — Interacción

Los elementos visuales deberán responder a las acciones del usuario.

## RF-10 — Personalización

El usuario deberá poder modificar determinadas propiedades visuales como:

- Intensidad.
- Velocidad.
- Color.
- Tipo de visualización.

---

# 23. Requisitos no funcionales

## RNF-01 — Usabilidad

La interfaz deberá ser intuitiva y permitir que el usuario comprenda las acciones principales sin instrucciones extensas.

## RNF-02 — Rendimiento

Las animaciones deberán ejecutarse de manera fluida dentro de las capacidades del dispositivo utilizado para el prototipo.

## RNF-03 — Diseño responsive

La arquitectura deberá permitir futuras adaptaciones para diferentes tamaños de pantalla.

## RNF-04 — Escalabilidad

El sistema deberá permitir agregar posteriormente:

- Nuevos géneros.
- Nuevas canciones.
- Nuevas visualizaciones.
- Nuevas interacciones.

## RNF-05 — Mantenibilidad

El código deberá organizarse de forma modular para facilitar futuras modificaciones.

# 31. Principios de diseño

El producto seguirá cinco principios principales:

### 1. Música primero

La música será el estímulo principal de la experiencia visual.

### 2. Interacción

El usuario debe participar activamente y no limitarse a observar.

### 3. Exploración

No existirá una única interpretación visual correcta.

### 4. Identidad

Cada género deberá tener características visuales reconocibles.

### 5. Escalabilidad

Las decisiones del MVP deberán permitir ampliar el proyecto posteriormente.

# 32. Definición del MVP

El **MVP de Sinestesia Digital** será una experiencia web funcional que permita:

> **Seleccionar uno de tres géneros musicales, reproducir una de dos canciones predeterminadas y experimentar una visualización que reaccione al audio y pueda ser modificada mediante diferentes interacciones.**

### Fórmula del MVP

**3 géneros**

×  

**2 canciones**

=

**6 experiencias audiovisuales**

+

**Interacción**

+

**Visualización reactiva**

+

**Ingeniería de Prompt**

=

**Sinestesia Digital — MVP 0.1**

# 33. Visión a futuro

Sinestesia Digital podrá evolucionar de un prototipo experimental a una plataforma de experiencias audiovisuales generativas.

La visión a largo plazo es permitir que cada usuario pueda **explorar, modificar e incluso crear su propia interpretación visual de la música**, utilizando herramientas de inteligencia artificial, programación creativa y diseño hipermedia.

El prototipo actual representa el primer paso para validar esta idea.
